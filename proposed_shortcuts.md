## About

Below is a table of proposed shortcuts for using with the Create Tab of Scalable Vector Shapes 2D.

Also included are standard shortcuts for other common tools and actions in case they are implemented in the future.

Note: All shortcuts are the same across Linux and Windows OS. Mac OS uses the following key equivalents.

| Linux, Windows | Max OS |
| -------------- | ------ |
| Ctrl           | Cmd    |
| Alt            | Opt    |
